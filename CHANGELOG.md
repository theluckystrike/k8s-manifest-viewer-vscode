# Changelog

## 0.1.0

- First release: `*.k8s.yaml`, `*.k8s.yml`, `deployment.yaml`, `service.yaml`, `ingress.yaml`, `kustomization.yaml` and any open YAML file in a read-only offline inspector, parsed locally with plain JavaScript.
- Multi-document resource tree (Kind, Namespace, Name, Replicas), container security posture checks (privileged containers, root user, missing resource limits, `:latest` tags, deprecated `apiVersion` values) and label-to-selector match table.
- Zovo Pro tools with 1 free try each: Markdown Kubernetes security audit report, two-manifest Markdown diff, and CSV and Markdown workload inventory export. Get Zovo Pro first shows what Pro includes and the tries left, in an editor tab.
